# Seguimiento del Proyecto HealthKids2

## Propósito

Registrar el avance del proyecto y verificar el cumplimiento de las actividades planificadas.

## Actividades de seguimiento

- Revisión del avance de las historias de usuario.
- Revisión de funcionalidades desarrolladas.
- Identificación de problemas.
- Revisión de tareas pendientes.
- Actualización del estado de las actividades.

## Herramientas utilizadas

- Trello para la gestión visual de tareas.
- GitHub para el control y documentación de cambios.
- Git para mantener el historial de modificaciones.

## Control

El seguimiento permite identificar desviaciones y tomar acciones correctivas cuando sea necesario.
