# Lecciones Aprendidas

## Organización

La documentación debe mantenerse organizada desde el inicio del proyecto.

## Seguimiento

Registrar periódicamente el avance permite detectar problemas antes de que afecten significativamente al proyecto.

## Comunicación

La comunicación entre los integrantes facilita la resolución de problemas y la coordinación de actividades.

## Control de cambios

Los cambios deben documentarse para conservar un historial claro de las modificaciones realizadas.

## Mejora continua

Las experiencias obtenidas durante el proyecto pueden utilizarse para mejorar futuros proyectos.
