# HealthKids2 - Documentación del Proyecto

## Descripción

Este repositorio contiene la documentación generada durante las diferentes fases del proyecto HealthKids2.

HealthKids2 es un proyecto de software orientado al seguimiento de la salud y aprendizaje infantil.

## Objetivo del repositorio

Centralizar, organizar y controlar la documentación relacionada con el desarrollo del proyecto.

## Estructura de la documentación

### 01 - Diseño y Planificación
Contiene la documentación relacionada con los objetivos, requisitos e historias de usuario.

### 02 - Ejecución, Seguimiento y Control
Contiene el seguimiento del desarrollo y el registro de incidencias.

### 03 - Evaluación y Cierre
Contiene la evaluación de resultados y las lecciones aprendidas.

### 04 - Sistema de Archivo
Describe la organización y clasificación de la documentación del proyecto.

## Capítulo 6

Este repositorio se utiliza como evidencia práctica del Capítulo 6: Documentación.

Los principales temas aplicados son:

- Diseño y planificación.
- Ejecución, seguimiento y control.
- Evaluación y cierre.
- Sistemas de archivo.
